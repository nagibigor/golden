# 🧹 Golden Touch Cleaning | Landing Page

Uma landing page moderna, responsiva e elegante desenvolvida para a **Golden Touch Cleaning**, empresa especializada em serviços de limpeza residencial e comercial de alto padrão no Condado de Kildare, Irlanda.

---

## 📌 Sobre o Projeto

O objetivo deste projeto foi criar uma plataforma digital atraente, intuitiva e focada na conversão de novos clientes, transmitindo o profissionalismo e o padrão de luxo (5 estrelas) oferecidos pela empresa.

### ✨ Destaques do Projeto

- **Apresentação de Serviços**: Seções detalhadas para Limpeza Residencial, Comercial, Limpeza Profunda (Deep Clean) e Pós-Construção.
- **Roteamento Dinâmico via WhatsApp**: Formulário interativo e botões de CTA que redirecionam o cliente diretamente para uma conversa de orçamento no WhatsApp com dados pré-preenchidos.
- **Prova Social**: Seção dedicada a avaliações verifcadas do Google para gerar credibilidade e confiança.
- **Perguntas Frequentes (FAQ)**: Respostas claras sobre verificações de antecedentes (Garda Vetting), seguros e políticas da empresa.
- **Área de Cobertura**: Mapeamento e lista das principais cidades/distritos atendidos no Condado de Kildare (Naas, Maynooth, Newbridge, Celbridge, Leixlip, etc.).
- **Design Responsivo & High-End**: Interface otimizada para dispositivos móveis e desktops, alinhada à identidade visual de alto padrão da marca.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 / CSS3**: Estrutura e estilização moderna com suporte a temas visuais de alto padrão.
- **JavaScript (JS)**: Interatividade, validação e integração com API do WhatsApp.
- **SEO & Performance**: Estruturado para boa indexação em mecanismos de busca e carregamento rápido.
